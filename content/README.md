# Stato del contenuto

I file MDX presenti in questa directory costituiscono il **corpus legacy non
verificato**. Sono conservati per audit, confronto e migrazione, ma:

- non sono una fonte normativa ufficiale;
- non sono la fonte canonica futura del progetto;
- non devono essere presentati come completi o fedeli;
- non devono essere corretti in massa prima della definizione del modello
  canonico v2;
- non possono essere promossi a release tramite il package corrente.

Lo stato macchina è dichiarato in `corpus-status.json`. La fotografia
riproducibile dei difetti noti è in `reports/validation/baseline.json`.

Le modifiche a questa directory devono essere limitate a correzioni urgenti
motivate o a operazioni di migrazione tracciate. Qualunque cambiamento
intenzionale richiede l'aggiornamento esplicito della baseline.
